# Custom WordPress Blog Theme

A WordPress theme built from scratch for a Web Programming course — no page builder, hand-written template hooks.

## What this does

- Custom theme templates: header, footer, single-post view, pagination, sliders, widgets — built with PHP template hooks
- Local development environment via XAMPP (Apache + MySQL) connected to WordPress
- Handles post display, navigation, and a custom 404 page

## Tech stack

PHP · HTML · CSS · JavaScript · MySQL · WordPress · XAMPP

## Team

Built with Meet Tagadiya.

## How to run

1. Install XAMPP and start Apache + MySQL
2. Drop this theme folder into `wp-content/themes/`
3. Activate it from the WordPress admin dashboard
